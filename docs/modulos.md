# Listado de módulos

Prioridades: **P0** imprescindible para el MVP, **P1** importante, **P2** deseable si sobra tiempo.

| Módulo | Descripción | Prioridad |
|---|---|---|
| Autenticación | Login de organizadores y staff, permisos por rol y alta de staff por invitación. | P0 |
| Productoras | Alta de productoras con su primer organizador (en el MVP, por seed). | P0 |
| Usuarios | Organizadores y staff de cada productora, y su asignación a eventos. | P0 |
| Catálogo | ABM de los productos que la productora vende en sus eventos. | P0 |
| Categorías | Agrupación y orden de los productos en el catálogo. | P1 |
| Eventos | ABM de eventos con horario de inicio y fin, y QR de acceso. | P0 |
| Oferta del evento | Precio, stock y disponibilidad de cada producto en un evento, editables durante el evento. | P0 |
| Demanda pendiente | Unidades vendidas y todavía no retiradas, por producto, para la barra. | P1 |
| Clientes | Identificación del cliente sin cuenta, con una cookie. | P0 |
| Carrito | Armado de uno o varios tickets antes de pagar. | P0 |
| Pedidos | Confirmación de la compra con reserva de stock. | P0 |
| Pagos | Pago simulado, preparado para sumar Mercado Pago. | P0 |
| Tickets | Mis tickets y QR de retiro de cada uno. | P0 |
| Canje | Escaneo del QR en la barra y entrega del pedido. | P0 |
| Auditoría | Registro de cambios de precio, stock y disponibilidad. | P1 |
| Historial | Eventos finalizados con lo vendido. | P1 |
| Reportes | Facturación de la noche y productos más vendidos. | P2 |
